# note 月5万円プロジェクト 運用キット

AI活用ノウハウを軸に、note で月5万円（手取り）を目指すための実行キットです。
企画から執筆までを Claude Code で自動化し、集客（SEO + X）と最終チェックだけ人が舵を取ります。

## 🎯 確定した方針（2026-06時点）

- **ジャンル**：AI活用ノウハウ（Claude Codeでの自動化実録）
- **売り方**：単発note（入口・980円）→ 月額メンバーシップ（1,000円）の2段構成
- **集客**：① Google SEO（主軸）＋ ② X（最小運用・ネタはClaude Codeが作成）
- **価格**：単発 980円 / メンバーシップ 月1,000円
- **自動化**：執筆は Claude Code が全自動／事実確認・最終投稿だけ人
- **目標**：メンバーシップ 約60人 ＝ 手取り 約5万円/月（到達目安 3〜4ヶ月）

## 🚀 使い方（毎日のルーティン）

### Xの運用（あなた：1日10分・コピペのみ）
1. `03_x-posts-batch01.md` から今日の投稿を選ぶ
2. Xにコピペして投稿
3. `04_x-post-tracker.csv` に結果（いいね・インプレ等）を記録
4. ネタが切れたら Claude Code に「次の30本作って」と頼む

### 記事の作成（Claude Code：あなたは最終チェックのみ）
1. `pipeline/article-pipeline.md` の手順に沿って Claude Code に依頼
2. 生成された記事の事実確認・推敲を5〜10分
3. note に投稿し、価格を設定
