## 【無料公開】レシピ1：長文メール → 読みやすい要点に変換

長いメールや資料を受け取って、「結局何が言いたいの？」となること、ありますよね。
これをAIに3秒で要約させます。コピペで使える指示文がこちら。

```
以下の文章を、忙しい人向けに要約してください。
- 最初に「結論」を1行で
- 次に「重要ポイント」を3つまで箇条書き
- 最後に「自分がとるべきアクション」があれば1行で
- 元の文章にない情報は足さないこと

【ここに長文を貼る】
```

ポイントは**「結論→ポイント→アクション」の順を指定する**こと。
これだけで、ダラダラした要約ではなく「すぐ動ける要約」になります。

## レシピ2：議事録・箇条書きメモを清書する

会議中に殴り書きしたメモを、提出できる議事録に整えます。

```
以下の箇条書きメモを、社内共有用の議事録に清書してください。
- 「決定事項」「ToDo（担当者つき）」「保留・課題」の3項目に分類
- 口語や崩れた表現は、丁寧で簡潔な書き言葉に直す
- 不明な点は【要確認】と明記し、勝手に補完しない

【メモを貼る】
```

「勝手に補完しない」の一文が重要。AIが事実を創作するのを防ぎます。

## レシピ3：調べ物を「出典つき要約」にまとめる

```
「【調べたいテーマ】」について、信頼できる情報を調べて要約してください。
- 要点を5つまで
- それぞれに出典（URLや情報源）を添える
- 不確かな情報は「要確認」と明記
- 古い情報の可能性があれば指摘する
```

出典を必ず添えさせることで、**そのまま鵜呑みにせず裏取りできる**状態にします。

## レシピ4：文章のトーンを相手に合わせる

同じ内容でも、相手によって言い方を変えたいときに。

```
以下の文章を、3パターンの言い方に書き分けてください。
①目上・取引先向け（丁寧・フォーマル）
②同僚向け（簡潔・フランク）
③初心者向け（専門用語を避けてやさしく）
内容の意味は変えないこと。

【文章を貼る】
```

## レシピ5：アイデアを「比較表」に構造化する

頭の中のモヤモヤを、判断できる表に変えます。

```
以下の選択肢を比較表にしてください。
- 列：各選択肢
- 行：メリット / デメリット / コスト / 向いている人
- 最後に「どれがどんな人におすすめか」を一言ずつ

【選択肢を箇条書きで貼る】
```

## レシピ6：定型業務の手順書を自動で作る

「あの作業、どうやるんだっけ」をなくす手順書を量産します。

```
「【業務名】」の手順書を作ってください。
- 前提・必要なもの
- 手順を番号つきで（誰がやっても再現できる粒度で）
- つまずきやすいポイントと対処
- 最後にチェックリスト
初めてやる人でも迷わない粒度で書いてください。
```

引き継ぎ・マニュアル化が一気に進みます。

## レシピ7：自分専用の「指示文テンプレ集」を育てる

ここが一番大事です。**うまくいった指示文を捨てずに貯める**こと。

```
これまでにうまくいった指示文を、再利用しやすいテンプレート集に整理してください。
- カテゴリ別に分類（メール / 要約 / 資料作成 など）
- 各テンプレに「使う場面」を一言添える
- 穴埋め部分は【　】で分かりやすく
```

これを1つのファイルにして育てていくと、
**あなた専用の「自動化マニュアル」**ができあがります。これが一番の資産です。

## 使うときの3つの注意（安全に自動化を続けるため）

1. **出てきた結果は必ず最後に自分でチェック**（特に事実・数字・固有名詞）
2. **機密情報・個人情報は安易に貼らない**（業務利用は会社のルールを確認）
3. **「勝手に補完しない」を指示に入れる**（AIの創作＝誤情報を防ぐ）

- 最後のチェックだけは人がやる——これが安全に続けるコツ
