# 投稿管理スプレッドシートの使い方

`04_x-post-tracker.csv` は、X投稿の「予定・実績・効果測定」を1枚で管理するシートです。

---

## Googleスプレッドシートに取り込む手順

1. [Googleスプレッドシート](https://sheets.google.com) を開く
2. 「ファイル」→「インポート」→「アップロード」
3. `04_x-post-tracker.csv` を選択
4. 「インポート場所：新しいスプレッドシートを作成」→ インポート
5. 完了。以後はスプレッドシート上で直接編集

> Excel派の人はそのまま `.csv` をExcelで開けばOK（文字化けする場合はUTF-8で開く）。

---

## 列の意味

| 列 | 内容 | 記入タイミング |
|---|---|---|
| 投稿ID | `03_x-posts-batch01.md` のポスト番号（A-1等） | 投稿前 |
| 予定日 / 投稿時間帯 | いつ出すか | 投稿前 |
| ピラー | 投稿の種類（A〜F） | 投稿前 |
| テーマ / 本文の冒頭 | どんな内容か（一覧で見分ける用） | 投稿前 |
| ハッシュタグ / note誘導 / リンク先 | 設定内容 | 投稿前 |
| ステータス | 投稿予定 → 投稿済 に変える | 投稿時 |
| いいね数 / インプレッション / リプライ / リポスト | Xのアナリティクスから転記 | 投稿の翌日 |
| プロフクリック / noteクリック | 一番大事な“集客”の指標 | 投稿の翌日 |
| メモ・気づき | 伸びた理由・反省 | 随時 |

---

## 運用フロー（週次）

1. **投稿時**：ステータスを「投稿済」に
2. **翌日**：Xアナリティクスを見て数字を転記（特に `noteクリック`）
3. **週1回**：反応の良かったピラー・テーマを確認
4. **ネタ補充**：Claude Code に「このCSVの数字を見て、伸びた型でバッチ02を30本作って」と依頼

---

## 一番見るべき指標

> **「noteクリック」と「プロフクリック」**

いいね・インプレッションは"見られた"だけ。
**実際にnoteへ送れた数こそが、月5万円に直結するKPI**です。
ここが伸びる投稿の型を見つけて、そればかり量産するのが勝ち筋。

## 補足：実物のGoogleスプレッドシートが欲しい場合

このCSVを元に、Claude Code 経由であなたのGoogle Driveに
