## 3. AI生成記事の規約（結論：書くのはOK。ただし条件あり）

### ✅ OK
- **AIで記事を書くこと自体は禁止されていない。** note公式もAIアシスタント機能を提供している。
- AI生成物の著作権は、それを使ったクリエイターに帰属する。
- **AI利用の開示義務は、規約上は明記されていない**（書いても書かなくてもよい。ただし下記の責任は負う）。

### ❌ NG（＝アカウント停止リスク）
| 禁止 | 内容 |
|---|---|
| **スパム・機械的な大量投稿** | AIで薄い記事を自動で量産する行為が該当しやすい。最重要注意点 |
| **著作権・知的財産権の侵害** | AI生成物が他者の権利を侵害していないか確認する責任はクリエイター |
| **誤情報・デマの流布** | AIの誤り（ハルシネーション）をそのまま出すと該当しうる |
| **情報商材的なもの** | マルチ商法等、ユーザーに不利益をもたらす情報の販売は禁止 |
| 差別・誹謗中傷・わいせつ・違法行為の助長 | 一般的な禁止事項 |

### 📌 補足
- note AIアシスタントは2025年2月よりGoogle（Gemini）ベース。**Googleの生成AI使用禁止ポリシーの遵守**が利用条件。
- クリエイターは「自分の作品をAIに学習させない」意思表示設定が可能（設定→アカウント設定）。
