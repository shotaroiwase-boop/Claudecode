# プロンプト④：セルフレビュー（AIに自己採点させる）

執筆後、投稿前に必ず通す工程。AIにレビューさせた上で、★最後はあなたが確認。

---

```
あなたは厳しいnote編集者です。今書いた記事を、辛口でレビューしてください。

次の観点で、各項目を5段階評価＋改善点を出して：

1. 課題解決：読者の悩みは本当に解決されているか？薄くないか？
2. 具体性：コピペできる手順・具体例は十分か？
3. タイトルと中身の一致：タイトルの期待を裏切っていないか？
4. 有料パートの価値：お金を払う価値があるか？無料部分で十分と思われないか？
5. 事実の正確さ：誤情報・古い情報・要確認の箇所はどこか（リストアップ）
6. 規約・品質リスク：スパム的・薄すぎ・使い回しに見える箇所はないか？
7. SEO：検索されるキーワードが自然に入っているか？

最後に：
- このまま出すなら何点（100点満点）か
- 70点未満なら、何を直せば合格かを具体的に
- 私（人間）が必ず確認すべき箇所を箇条書きで
```

---

## ★ この後、あなたがやること（5〜10分・省略不可）

1. AIがリストした「事実の要確認」箇所を自分で確認・修正
2. 自分で通し読みして、違和感・嘘っぽさがないかチェック
3. 自分の体験・実数を1つでも足す（リアリティが信頼になる）
4. これでOKなら投稿へ

> ここを飛ばすと、誤情報や規約違反のリスクが残ります。最後の砦です。
