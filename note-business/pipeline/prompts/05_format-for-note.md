# プロンプト⑤：note投稿用に整形

レビュー済みの本文を渡して、note投稿に最適化します。

---

```
この記事をnoteに投稿する形に整えてください。

1. 見出し整形：noteで読みやすいようにH2/H3を整理（見出しは具体的に）
2. リード文：冒頭に、検索とSNSで興味を引く100〜150字の導入文
3. 記事の要約：note入力欄用に100字程度の説明文
4. ハッシュタグ：noteで付けるべきタグを5個（ジャンル＋具体テーマ）
5. 有料設定の提案：
   - この記事を有料にするなら推奨価格（無料 / 500 / 980 / 1,500円のどれか＋理由）
   - 有料ラインを引く具体的な位置（どの見出しの直前か）
   - 無料パートの締めの一文（「ここから先は…」の自然な誘導文）
6. アイキャッチの方向性：どんな画像が合うか一言（自分で用意する用）
7. CTA：記事末尾に入れる、メンバーシップへの誘導文（押し付けすぎない自然な形）

出力はそのままnoteに貼れるMarkdownで。
```

---

## 使い方メモ
- ★ 推奨価格はあくまで提案。最終判断はあなた
- 入口商品は980円、需要が読めない最初の数本は500円〜で様子見もアリ
- 記事末尾のメンバーシップCTAは毎回入れる（地味だが効く動線）
