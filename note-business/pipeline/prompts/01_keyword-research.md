# プロンプト①：キーワード・お悩み調査

そのまま Claude Code にコピペして使ってください。

---

```
あなたはnoteで稼ぐためのコンテンツ戦略家です。

【ジャンル】AI活用ノウハウ（特にClaude Code / 生成AIで作業や副業を自動化する方法）
【読者】AIに興味はあるが何から始めればいいか分からない、20〜40代の会社員・副業志望者

このジャンルで、note記事として需要がありそうな「具体的な悩み・検索されそうなキーワード」を
WebSearchも使って10個提案してください。

各候補について、次の形式で出して：
- テーマ（記事タイトルになりそうな悩み）
- 想定検索キーワード（GoogleでこのキーワードでSEOを狙う）
- 需要の根拠（なぜ需要があると考えるか / 競合の有無）
- 有料 or 無料 どちらに向くか（有料にできる深さがあるか）
- 想定単価（無料 / 500円 / 980円 / 1,500円 など）

最後に、「最初に書くべきおすすめの1本」を理由つきで1つ選んでください。
```

---

## 使い方メモ
- 出てきた候補から、自分が少しでも書けそう＆需要のありそうなものを選ぶ
- 「有料に向く」かつ「単価980円以上」のテーマは、入口商品の候補になる
- 無料向けのテーマは、SEO集客の入口記事に回す
