# プロンプト②：タイトル・構成案

`[テーマ]` を埋めてから Claude Code に渡してください。

---

```
あなたはnoteで売れる記事を設計する編集者です。

【テーマ】[ここに①で選んだテーマを書く]
【ジャンル】AI活用ノウハウ
【読者】[誰のどんな悩みか。例：ChatGPTは触ったが作業の自動化までできていない会社員]
【記事タイプ】[無料 or 有料980円]

以下を作ってください。

1. タイトル案を5つ
   - 具体的な悩み or 数字 or 「やり方/手順」を入れる
   - 検索（SEO）とクリック両方を意識
   - それぞれ狙いを一言添えて

2. 記事の構成（見出しレベルで）
   - 導入（読者の悩みへの共感＋この記事で解決できること）
   - 本論の見出し（H2を4〜6個、各H2の下に要点を箇条書き）
   - まとめ（次のアクション）

3. 有料記事の場合：
   - 「無料パート / 有料パート」の境界をどこに置くか提案
   - 無料パートで価値を感じさせ、有料パートで具体的な答えを出す設計に

注意：
- 文字数は追わない（長さと売上は無関係というデータがある）
- 1記事で解決する悩みは1つに絞る
```

---

## 使い方メモ
- ★ ここであなたがタイトルを1つ選ぶ（一番大事な人の判断）
- 有料/無料の境界は、提案を見て調整する
