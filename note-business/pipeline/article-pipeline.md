# 記事 自動生成パイプライン

Claude Code で「企画→構成→執筆→整形」を回すための運用手順です。
あなたが手を動かすのは ★ マークの工程（事実確認・最終判断）だけ。

---

## 全体フロー

```
① キーワード/お悩み調査   → Claude Code（needs:WebSearch）
② 構成・タイトル案        → Claude Code（複数案）→ ★あなたが1つ選ぶ
③ 本文執筆（無料/有料）   → Claude Code
④ ★事実確認＋推敲        → あなた（5〜10分）＋ AIセルフレビュー
⑤ note投稿用に整形        → Claude Code（見出し・要約・価格提案）
⑥ ★投稿・価格決定        → あなた（最終判断）
⑦ X宣伝文・SEOタイトル    → Claude Code
```

各工程のプロンプトは `prompts/` フォルダにあります。
そのままコピペして Claude Code に渡してください。

---

## 使い方（1記事を作る流れ）

### STEP 1：ネタを決める
`prompts/01_keyword-research.md` を Claude Code に渡す。
→ 需要のある「悩みキーワード」と記事テーマ候補が10個ほど出る。
→ 作りたいテーマを1つ選ぶ。

### STEP 2：構成を作る
`prompts/02_outline.md` のテンプレに、選んだテーマを入れて渡す。
→ タイトル案5つ＋見出し構成が出る。
→ ★ あなたがタイトルを1つ選ぶ。

### STEP 3：執筆させる
`prompts/03_write-article.md` に構成を渡す。
→ 無料パート＋有料パートの本文が出る。

### STEP 4：チェックする（★人の工程）
`prompts/04_self-review.md` でAIに自己レビューさせる。
→ その後、あなたが5〜10分で事実確認・違和感の修正。
→ ここだけは絶対に省略しない（規約・品質・信頼のため）。

### STEP 5：投稿用に整える
`prompts/05_format-for-note.md` を渡す。
→ note用の見出し整形・100字程度の要約・推奨価格・有料ラインの位置が出る。

### STEP 6：投稿する（★人の工程）
note に貼り付け、価格を決めて公開。

### STEP 7：拡散用の文面を作る
`prompts/06_promo-x.md` を渡す。
→ この記事用のX宣伝ポスト＋SEOを意識したタイトル違い案が出る。

## まとめて一気にやりたい場合

慣れたら、以下を Claude Code に一言で頼めば①〜⑤を連続実行できます：

```
note-business/pipeline/prompts/ の手順に沿って、
「[テーマ]」というテーマでnote記事を1本作って。
①キーワード調査→②構成→③執筆→④セルフレビュー→⑤note整形まで通しでやって、
articles/ に保存して。最後に私がチェックする箇所を教えて。
```

---

## 品質を保つための原則（重要）

- **長さを追わない**：note公式データで「文字数と売上はほぼ無関係」。濃さで勝負。
- **悩みを1つに絞る**：1記事1テーマ。あれもこれも入れない。
- **有料ラインの位置**：無料パートで「価値がありそう」と思わせ、有料パートで「具体的な答え」を出す。
- **使い回し禁止**：同じ構成のコピペ量産は規約・SEO両面でNG。テーマごとに作る。
- **★最終チェックは必須**：AI出力をそのまま投稿しない。
