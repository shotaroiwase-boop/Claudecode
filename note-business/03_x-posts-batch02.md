## ピラーA：ノウハウTips（具体手順を1つ無料で）

**A-7**
```

```

**A-8**
```

「出典（URL）を必ず添えて。不確かな情報は"要確認"と書いて」

これを入れないと、それっぽい嘘が混ざります。
出典を出させる=裏取りできる状態にする。

```

**A-9**
```
議事録づくり、もう手で清書しなくていいです。

殴り書きメモをAIに渡してこう頼む👇
「決定事項/ToDo(担当者つき)/保留 の3つに分類して清書して。不明点は勝手に補完しないで」

"補完しないで"が地味に超重要。
創作（誤情報）を防げます。
```

**A-10**
```
同じ内容を相手別に書き分けるプロンプト。

「この文章を①取引先向け②同僚向け③初心者向け の3パターンで。意味は変えないで」

メール1本にいちいち悩む時間、消えます。
```

**A-11**
```
迷ったときはAIに「比較表」を作らせる。

「この選択肢を、メリット/デメリット/コスト/向いてる人 の表にして」

頭のモヤモヤが、判断できる表に変わる。
意思決定がめちゃ速くなります。
```

**A-12**
```
AI自動化で一番大事なの、実はこれ。

「うまくいった頼み方を捨てずに貯める」

成功した指示文をテンプレ集にしていくと、
```
