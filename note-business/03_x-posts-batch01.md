# Xポスト案 バッチ01（コピペ用 30本）

使い方：上から順でも、ピラーをバラしてでもOK。1日1〜3本コピペして投稿し、結果を `04_x-post-tracker.csv` に記録。
※ `〇〇` や `[ ]` の部分はあなたの実体験に置き換えてください（数字や具体例が入るほど伸びます）。
※ AIで作った文面です。投稿前に30秒だけ目視チェックを。

---

## ピラーA：ノウハウTips（具体手順を1つ無料で）

**A-1**
```
AIに記事を書かせると「薄い文章」になる人へ。

原因はだいたいコレ👇
「〇〇について書いて」と丸投げしてる。

✅改善：
①読者の悩みを1つに絞る
②結論を先に指定する
③具体例を必ず入れさせる

これだけで質が激変します。
```

**A-2**
```
Claude Code で記事を量産しようとして失敗した話。

長文を大量生産→ぜんぜん読まれない。

調べたら、note公式データで「文字数と売上はほぼ無関係」だった。

長さじゃなくて"悩みをどれだけ解決したか"が全て。
方針を変えたら反応が変わりました。
```

**A-3**
```
AIで作業を自動化するときのコツ。

「全部を自動化しよう」とすると挫折します。

おすすめは"工程を分解して1つずつ"
①ネタ出し→自動
②構成→自動
③執筆→自動
④事実確認→手動（ここだけ人）

最後のチェックだけ残すと、品質も保てて楽。
```

**A-4**
```
ChatGPTより Claude Code が便利だと感じた瞬間。

「ファイルを作って、整理して、まとめて」が
会話の中で完結する。

コピペの往復が消えると、作業が一気に速くなる。
"対話"じゃなくて"作業を任せる"感覚が近いです。
```

**A-5**
```
AIプロンプトで一番効くテクニック、たぶんコレ。

❌「〇〇を書いて」
⭕「あなたは〇〇の専門家です。読者は△△で悩む初心者。結論から、具体例を3つ入れて書いて」

役割・読者・形式を指定するだけ。
今日から使えます。
```

**A-6**
```
AIに任せる前にやると激変すること。

「誰の、どんな悩みを、どう解決するか」を
1行で書き出す。

これをやらずにAIに投げると、
ふわっとした使えない文章が出てくる。

設計が9割。生成は1割。
```

## ピラーC：失敗談・学び（共感＆信頼）

**C-1**
```
AIで記事を量産すれば稼げる、と思ってた過去の自分へ。

甘かった。

・無確認で出した記事は内容が薄い
・同じ構成の使い回しは読まれない
・長く書いても売れない

"AIに丸投げ"じゃなく"AIと設計"が正解でした。
```

**C-2**
```
最初の有料記事、まったく売れませんでした。

原因を分析したら、
「誰の悩みを解決するか」が曖昧だった。

万人向け=誰にも刺さらない。

ターゲットを1人に絞り直したら、ようやく初購入。
当たり前のことが一番むずかしい。
```

**C-3**
```
SNSゼロから始めて痛感したこと。

「いい記事を書けば見つけてもらえる」は幻想。

どんなに良くても、入口（X・SEO）がないと
誰の目にも触れない。

中身と同じくらい"届け方"が大事でした。
```

**C-4**
```
note運用でやらかしかけた話。

AIで作った記事をそのまま大量投稿しようとして、
「これスパム判定されるのでは…」と気づいて止めた。

規約と品質、ちゃんと確認大事。
楽したくても、最後の人の目だけは外せない。
```
